
**Вариант 6 — Редактор последовательности преобразований.**

## Описание алгоритмов

### Матрица преобразований 4×4 (`core/matrix4x4`)

Все геометрические преобразования представлены однородными матрицами 4×4.  
Это позволяет объединять любое количество операций в одну матрицу через перемножение,
и применять всю цепочку к каждой точке ровно **одним** матрично-векторным умножением.

| Операция | Матрица |
| --- | --- |
| **Смещение** `(dx, dy, dz)` | Единичная с `m[0][3]=dx`, `m[1][3]=dy`, `m[2][3]=dz` |
| **Поворот X** на угол `θ` | Блок `[[1,0,0],[0,cosθ,−sinθ],[0,sinθ,cosθ]]` |
| **Поворот Y** на угол `θ` | Блок `[[cosθ,0,sinθ],[0,1,0],[−sinθ,0,cosθ]]` |
| **Поворот Z** на угол `θ` | Блок `[[cosθ,−sinθ,0],[sinθ,cosθ,0],[0,0,1]]` |
| **Масштаб** `s` | Диагональ `(s, s, s, 1)` |

**Композиция** цепочки из N преобразований:
```
M = M₁ × M₂ × ... × Mₙ
```

Матрицы перемножаются слева направо в порядке добавления.  
Функция `composeMatrix(k)` в `MainWindow` строит частичную матрицу для первых `k` шагов — это основа пошаговой визуализации.


Реализованы две версии:

**Последовательная** — обычный цикл `for` по всем точкам:
```
void PointCloud::applyMatrixSequential(const Matrix4x4& mat) {
    for (auto& p : points)
        p = mat.transformPoint(p);
}
```

**Параллельная** — через `std::execution::par` из C++17:
```
void PointCloud::applyMatrixParallel(const Matrix4x4& mat) {
    std::for_each(std::execution::par,
                  points.begin(), points.end(),
                  [&](Point3D& p) { p = mat.transformPoint(p); });
}
```

### Визуализация (`QGraphicsScene`)

Каждая точка рисуется как эллипс 2×2 px в проекции XY (ось Y инвертирована для экранной системы координат):

```
scene->addEllipse(p.x, -p.y, 2, 2, QPen(), QBrush(Qt::white));
```

## Сборка и запуск

### Требования

- **Qt 6.x** (компоненты: `Widgets`)
- **CMake 3.16+**
- Компилятор с поддержкой **C++17**

### Windows (Qt Creator)

1. Установить **Qt 6** через [Qt Online Installer](https://www.qt.io/download)
2. Открыть `CMakeLists.txt` в **Qt Creator**
3. Выбрать kit с компилятором MSVC 2019+ или MinGW
4. **Build → Run** (`Ctrl+R`)

### Windows (командная строка, MSVC)

```cmd
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
.\build\Release\PointCloudEditor.exe
```

## Использование

| Действие | Как |
| --- | --- |
| Загрузить облако | Кнопка **Load XYZ** → выбрать `.xyz` файл |
| Сгенерировать облако | Кнопка **Generate** (50 000 случайных точек) |
| Добавить преобразование | Кнопки **+ Translate / + Rotate X/Y/Z / + Scale** → ввод параметров |
| Удалить преобразование | Выбрать в списке → **Remove** |
| Очистить список | **Clear** |
| Применить (последовательно) | **Apply Sequential** — обычный цикл |
| Применить (параллельно) | **Apply Parallel** — `std::execution::par` |
| Просмотр по шагам | Слайдер внизу — от 0 (исходное) до N (все применены) |
| Прореживание | **Downsample** — оставляет каждую 2-ю точку |
| Итоговая матрица | Отображается в текстовом поле после Apply |
| Статистика | Количество точек и время обработки под матрицей |

### Формат XYZ-файла

```
# Комментарии игнорируются
0.123 -0.456 0.789
1.000  2.000 3.000
...
```

Каждая строка: три числа через пробел — координаты X, Y, Z.
